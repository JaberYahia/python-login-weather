# Login System with Weather Integration

This project is for me to improve and learn on different skills within programming. The main goal here is to improve on the concept of fundamentals, learn data handling, Error handling, APIs and HTTP. This project is a weather app that requires you to create a user account and login to the account to access the weather app.
  

## What I learned

So far I have learned about why gitignore is useful, I have the idea of data handling down as well as the concept of error handling which I'm still improving on. I learned the structure of using an api link to request data and turning that data into usable data through the json() command.

## What I'd improve

I want to improve the Ui of the program in the future by learning react. I also would like to learn and add password hashing and improve on error handling. I also want to have a storing method for users. 

 ## Features

 1. Users can create an account
 2. Users can login to an account
 3. Users can get a detailed forecast of their area



## How it works

hud.py is the main menu where you are able to create, login, or exit the program.
create.py is the main file that handles user creation
login.py is the main file that checks if login credentials are valid to login without issues. 

## Tools and APIs used 

Python 3, requests library, Open-Meteo.

## How to run it

1. Make sure you have Python 3 installed. You can check by running:

```python --version```

2. clone repository
``` git clone https://github.com/JaberYahia/python-login-weather.git```

3. access folder
 ```cd python-login-weather```

4. Install the required library: 
```pip install requests```

5. Run the main program:
``` python hud.py```
